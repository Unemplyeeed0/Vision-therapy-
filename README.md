# NeuroVision Therapy — Web MVP

A lightweight, mobile-friendly static prototype for a clinician-guided vision-training workspace.

## Run it
- Open `index.html` in a modern browser, or
- Upload the contents of this folder to a GitHub repository and enable GitHub Pages.

No build step, backend, account, or external dependency is required.

## MVP features
- Overview dashboard and local session history
- Exercise library
- Smooth-pursuit target demonstration
- Saccadic target localization demonstration
- Dichoptic display concept preview (not actual per-eye separation)
- Clinician planning panel stored locally in the browser

## Important limitations
This is a software demonstration, not a medical device, validated therapy, diagnostic tool, or clinical decision-support system. It does not measure visual acuity, suppression, vergence, fixation, stereopsis, eye movements, or treatment response. Do not prescribe activities or infer clinical improvement from scores or session time. Any clinical use requires qualified clinician oversight, stimulus calibration, evidence review, safety testing, privacy/security work, and appropriate regulatory assessment.
